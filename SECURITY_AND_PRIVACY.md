# Security and Privacy

GarageGrid describes the contents and organization of a real home, so privacy is part of the product design rather than an afterthought.

## Intentionally excluded from this repository

This presentation repository does **not** contain:

- Application source code
- Database files, migrations, or schema definitions
- Household inventory records
- Names, email addresses, passwords, or authentication data
- API keys, environment variables, or secrets
- Docker or deployment configuration
- Local-network addresses
- Private household, receipt, serial-number, or storage photographs
- Backup archives from the private project

## What this repository contains

Only a recruiter-facing product narrative, workflow diagrams, design rationale, and high-level technology summary are included. They explain the work without enabling reconstruction of the private application or exposing household data.

## Operating model

The working application is self-hosted and intended for access by authorized household members on a private local network. The database remains local.

## Public visibility

This repository may be temporarily public for portfolio review. It is separate from the private implementation repository and can be returned to private visibility without affecting the working application.

## Recruiter and hiring-manager review

Reviewers can understand:

- The problem being solved
- The product architecture at a conceptual level
- The workflow and usability decisions
- The scope of testing and iteration
- The role of AI-assisted development

They cannot access the source code, live application, household database, credentials, or private media.
